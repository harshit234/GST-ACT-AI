# Security Policy

## Supported Versions

Currently, GST ACT AI is in active development. Only the `main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of GST ACT AI seriously. If you discover a security vulnerability, please do NOT report it by opening a public GitHub issue. 

Instead, please email your findings to the repository maintainer (you can find contact details on their GitHub profile if public) or reach out privately. 

When reporting a vulnerability, please include:
- A description of the vulnerability and its impact.
- The steps required to reproduce the issue.
- Any relevant logs, code snippets, or error messages.

We will try to acknowledge your report within 48 hours and provide an estimated timeline for resolution.

## Current Security Posture
Please refer to the "Security and privacy" section in the `README.md` for a complete breakdown of implemented controls, trust boundaries, and known gaps (e.g., lack of webhook signature validation and rate limiting).

We encourage community contributions that address the listed security gaps or improve the overall security posture of the application.
